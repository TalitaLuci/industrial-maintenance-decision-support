# Roteiro de análise exploratória

Use este roteiro em `02_exploratory_analysis.ipynb`:

1. Carregar `train_FD001.txt` e executar `audit_data`.
2. Analisar número de motores, comprimento das trajetórias e dados ausentes.
3. Visualizar sensores selecionados ao longo dos ciclos para alguns motores.
4. Comparar sensores constantes/quase constantes e documentar exclusões.
5. Construir a RUL de treino e comparar alvo sem truncamento com uma alternativa truncada.
6. Salvar os gráficos e registrar as decisões no README.

Evite usar o teste oficial para selecionar features ou ajustar hiperparâmetros.
